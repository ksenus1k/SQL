# SQL Portfolio

## О проекте

Данный репозиторий содержит учебные и практические работы по SQL, выполненные в среде Microsoft SQL Server.
Работы направлены на освоение языка T-SQL, изучение принципов организации реляционных баз данных и приобретение практических навыков обработки, изменения и анализа данных.

## Технологии и инструменты

- **Microsoft SQL Server** — система управления реляционными базами данных.
- **SQL Server Management Studio (SSMS)** — среда разработки и администрирования баз данных.
- **T-SQL** — язык написания запросов и программирования в Microsoft SQL Server.

## Практические навыки

- Создание SQL-запросов для получения и обработки данных.
- Фильтрация, сортировка и группировка результатов запросов.
- Использование операторов JOIN для объединения данных из нескольких таблиц.
- Работа с первичными и внешними ключами.
- Выполнение операций INSERT, UPDATE и DELETE.
- Применение переменных, условных конструкций и циклов.
- Разработка и выполнение хранимых процедур.

## Проекты

### 1. Обработка и анализ данных с использованием T-SQL

**Технологии:** Microsoft SQL Server, T-SQL.

Реализованы SQL-запросы для получения, объединения и обработки данных о товарах, категориях и продажах.

**Основные возможности:**
- Объединение данных из нескольких таблиц с помощью JOIN.
- Использование временных таблиц и табличных переменных.
- Применение подзапросов и CTE.
- Агрегирование данных с помощью SUM и GROUP BY.
- Использование табличных функций.
