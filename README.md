# SQL Portfolio

## О проекте

Данный репозиторий содержит учебные и практические работы по SQL, выполненные в среде Microsoft SQL Server.
Работы направлены на освоение языка T-SQL, изучение принципов организации реляционных баз данных и приобретение практических навыков обработки, изменения и анализа данных.

## Технологии и инструменты

- **Microsoft SQL Server** — система управления реляционными базами данных.
- **SQL Server Management Studio (SSMS)** — среда разработки и администрирования баз данных.
- **T-SQL** — язык написания запросов и программирования в Microsoft SQL Server.

## Практические навыки

- Создание SQL-запросов для получения и обработки данных.
- Фильтрация, сортировка и группировка результатов запросов.
- Использование операторов JOIN для объединения данных из нескольких таблиц.
- Работа с первичными и внешними ключами.
- Выполнение операций INSERT, UPDATE и DELETE.
- Применение переменных, условных конструкций и циклов.
- Разработка и выполнение хранимых процедур.

## Проекты

### 1. Обработка и анализ данных с использованием T-SQL

**Технологии:** Microsoft SQL Server, T-SQL.

Реализованы SQL-запросы для получения, объединения и обработки данных о товарах, категориях и продажах.

**Основные возможности:**
- Объединение данных из нескольких таблиц с помощью JOIN.
- Использование временных таблиц и табличных переменных.
- Применение подзапросов и CTE.
- Агрегирование данных с помощью SUM и GROUP BY.
- Использование табличных функций.

**[Просмотреть проект](SQL-Queries/)**

### 2. Управление данными в Microsoft SQL Server

**Технологии:** Microsoft SQL Server, T-SQL.

Реализованы SQL-скрипты для добавления, обновления и удаления данных в реляционной базе данных с учётом связей между таблицами.

**Основные возможности:**
- Добавление новых записей с использованием INSERT INTO.
- Обновление данных с помощью UPDATE.
- Удаление записей с использованием DELETE.
- Работа со связанными таблицами и внешними ключами.
- Использование подзапросов и INNER JOIN.
- Получение идентификаторов записей с помощью SCOPE_IDENTITY().
- Применение условий WHERE для выборочного изменения данных.

**[Просмотреть проект](Data-Manipulation/)**

### 3. Программирование и автоматизация операций на T-SQL

**Технологии:** Microsoft SQL Server, T-SQL.

Реализованы SQL-скрипты для автоматизации обработки заказов, управления данными и изменения цен товаров с использованием программных конструкций T-SQL.

**Основные возможности:**

- Объявление и использование переменных с помощью DECLARE и SET.
- Создание заказов и добавление связанных записей с использованием INSERT INTO.
- Получение идентификаторов созданных записей с помощью SCOPE_IDENTITY().
- Проверка существования записей с использованием IF EXISTS.
- Применение условных конструкций IF и ELSE.
- Использование циклов WHILE и оператора BREAK для автоматизации изменения цен.
- Расчёт средней и максимальной стоимости товаров с помощью AVG и MAX.
- Обновление данных с использованием UPDATE.
- Работа с датами с помощью GETDATE() и DATEADD().
