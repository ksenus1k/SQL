# Обработка и анализ данных с использованием T-SQL

## Описание проекта

Проект посвящён получению, объединению и агрегированию данных в Microsoft SQL Server на примере базы данных SalesLT.
Реализованы SQL-запросы для обработки информации о товарах, их характеристиках и категориях, а также расчёта выручки по клиентам.

## Реализованные задачи

**1. Обработка данных о товарах**
- Объединение информации о товарах, моделях и их описаниях с использованием JOIN.
- Применение табличных переменных для обработки данных о цветах товаров.
- Создание и использование временных таблиц для работы с размерами товаров.
- Получение иерархии товарных категорий с использованием табличной функции.

**2. Анализ продаж**
- Объединение информации о клиентах и заказах.
- Расчёт суммарной выручки по клиентам с использованием SUM и GROUP BY.
- Использование вложенных запросов для предварительной обработки данных.
- Применение общих табличных выражений (CTE) для структурирования запросов.

## Использованные технологии

- Microsoft SQL Server
- T-SQL
- JOIN
- CTE (Common Table Expressions)
- Подзапросы
- Временные таблицы
- Табличные переменные
- Агрегатные функции
