# Управление данными в Microsoft SQL Server

## Описание проекта

Проект демонстрирует применение языка T-SQL для управления данными в реляционной базе Microsoft SQL Server.
Реализованы операции добавления, обновления и удаления записей, а также обработка связанных данных в таблицах товаров и товарных категорий.

## Реализованные задачи

### 1. Добавление данных (INSERT)
- Добавление новых товаров в базу данных.
- Создание товарных категорий и добавление связанных с ними товаров.
- Получение идентификатора добавленной записи с использованием SCOPE_IDENTITY().
- Использование вложенных запросов для определения идентификаторов категорий.

### 2. Обновление данных (UPDATE)
- Массовое изменение стоимости товаров выбранной категории.
- Установка даты прекращения продаж для определённых товаров.
- Применение условий WHERE для выборочного обновления записей.

### 3. Удаление данных (DELETE)
- Удаление товаров по заданным условиям.
- Последовательное удаление связанных записей с учётом ограничений внешних ключей.
- Проверка результатов удаления с использованием SELECT.

### 4. Работа со связанными таблицами
- Объединение данных с использованием INNER JOIN.
- Использование подзапросов при выполнении операций с данными.
- Учёт ссылочной целостности при удалении записей.

## Использованные технологии

- Microsoft SQL Server
- T-SQL
- INSERT, UPDATE, DELETE
- SELECT, WHERE
- INNER JOIN
- Подзапросы
- SCOPE_IDENTITY()
- GETDATE()
