# Программирование и автоматизация операций на T-SQL

## Описание проекта

Проект демонстрирует применение программных конструкций T-SQL для автоматизации операций в Microsoft SQL Server.

Реализованы SQL-скрипты для создания заказов, добавления товаров с проверкой существования записей и последовательного изменения цен на основе заданных условий.

## Реализованные задачи

### 1. Создание и обработка заказов
- Использование переменных для хранения параметров заказа.
- Создание новых записей в таблице заказов.
- Получение идентификатора созданного заказа с помощью SCOPE_IDENTITY().
- Проверка существования заказа с использованием IF EXISTS.
- Добавление товаров в существующий заказ.

### 2. Автоматизация изменения цен
- Расчёт средней и максимальной стоимости товаров.
- Использование цикла WHILE для последовательного изменения цен.
- Применение условного оператора IF и команды BREAK.
- Обновление данных с использованием UPDATE.
- Вывод результатов вычислений с помощью PRINT.

## Использованные технологии

- Microsoft SQL Server
- T-SQL
- DECLARE, SET
- IF EXISTS, ELSE
- WHILE, BREAK
- INSERT, UPDATE
- JOIN
- AVG, MAX
- SCOPE_IDENTITY()
- GETDATE(), DATEADD()
- PRINT, CONVERT()

## Примечание

SQL-скрипты предназначены для выполнения в тестовой базе данных SalesLT. Выполнение операций приводит к добавлению заказов и изменению цен товаров.
